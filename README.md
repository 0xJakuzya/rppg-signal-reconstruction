# Восстановление сигнала удалённой фотоплетизмографии из видеопотоков лица

Метод бесконтактной оценки пульсовой волны (remote photoplethysmography, rPPG /
blood volume pulse, BVP) по RGB-видео лица. Восстановление сигнала выполняется
пространственно-временной свёрточной нейронной сетью **PhysNet** (Yu et al.,
BMVC 2019); частота сердечных сокращений (ЧСС) извлекается из восстановленного
сигнала спектральным методом.

## Конвейер обработки

1. **Детекция лица.** По каждому кадру MediaPipe FaceLandmarker
   определяет ключевые точки; лицо вырезается по описывающему прямоугольнику с
   относительным расширением `face_margin_frac` и приводится к размеру
   `face_size × face_size`.
2. **Формирование окон.** Видео разбивается на перекрывающиеся временные окна
   длины `window` с шагом `stride`.
3. **Нормализация представления.** Кадры и метки преобразуются в представление
   `DiffNormalized`: нормированные разности соседних отсчётов, делённые на своё
   стандартное отклонение. Пропуски детекции лица восстанавливаются линейной
   интерполяцией; записи с долей пропусков выше порога отбраковываются.
4. **Восстановление сигнала.** PhysNet отображает окно `[T,3,H,W]` в сигнал
   `[T]`.
5. **Оценка ЧСС.** Частота выделяется по максимуму спектра мощности (БПФ) в
   полосе `[hr_lo_hz, hr_hi_hz]`.

## Модель и функция потерь

**PhysNet** — трёхмерная свёрточная сеть кодер-декодер: пространственно-временные
блоки `Conv3d–BatchNorm3d–ReLU` с чередующимся пулингом понижают разрешение,
транспонированные свёртки восстанавливают временну́ю ось, адаптивный пулинг
устраняет пространственные измерения, а завершающая свёртка `1×1×1` формирует
одномерный сигнал. Перед головой применяется `Dropout3d`.

**ShiftLoss** — устойчивая к фазовому сдвигу модификация функции потерь на основе
отрицательной корреляции Пирсона. Для каждого окна потери вычисляются при всех
сдвигах в диапазоне `±max_shift` отсчётов, и берётся минимум. Это компенсирует
дрейф задержки между видео и эталонным сигналом ФПГ, не штрафуя за постоянное
фазовое рассогласование.

## Протокол обучения

Обучение ведётся по схеме поэтапного переноса (transfer learning):
множество пациентов разбивается на группы по `transfer_group_size`; нулевой этап
обучается с нуля, последующие этапы
дообучают накопленные веса при малой постоянной скорости обучения `finetune_lr`,
что предотвращает разрушение ранее выученных представлений. Фиксированная
отложенная подвыборка (`transfer_val_patients`) используется для валидации на всех
этапах, обеспечивая сопоставимость контрольных точек. Лучшая контрольная точка
выбирается по сдвиг-инвариантной корреляции; ранняя остановка срабатывает при
отсутствии её прироста в течение `early_stop_patience` эпох.

Разбиение train/val выполняется по пациентам во избежание утечки данных.

## Данные и оценка

Обучение проводится на наборе **MCD-rPPG** (мультикамерный набор с
синхронизированными сигналами ФПГ), кросс-датасетная проверка — на **UBFC-rPPG**.
Качество оценивается посредней абсолютной ошибке (MAE) и среднеквадратичной ошибке (RMSE) оценки ЧСС, а также по корреляции восстановленного сигнала с эталоном (Корреляция Пирсона).

## Структура репозитория

```text
models/
  physnet.py       # PhysNet: 3D-CNN, [B, T, C, H, W] -> [B, T]
  loss.py          # ShiftLoss (сдвиг-инвариантная отрицательная корреляция Пирсона)

datasets/
  base.py          # DatasetReader
  mcd.py           # чтение MCD-rPPG (видео + синхронный ФПГ)
  ubfc.py          # чтение UBFC-rPPG (видео + синхронный ФПГ)

src/
  config.py        # параметры: пути, препроцессинг, гиперпараметры обучения
  face_detector.py # детекция лица (MediaPipe)
  preprocess.py    # видео и нормированные временные окна (.npz)
  dataset.py       # загрузка окон, разбиение по пациентам, этапы переноса
  utils.py         # детренд, полосовой фильтр, оценка ЧСС, метрики
  train.py         # цикл обучения с поэтапным переносом
  evaluate.py      # кросс-датасетная оценка (HR MAE / RMSE)
```

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Для использования GPU установите сборку PyTorch с поддержкой CUDA. Файл модели
`face_landmarker.task` должен находиться в корне проекта (путь задаётся в
`src/config.py`).

## Запуск

```bash
# 1. Подготовка временных окон из видео
python -m src.preprocess

# 2. Обучение модели
python -m src.train

# 3. Оценка сохранённой модели на отложенном наборе
python -m src.evaluate
```
